## What I learned This Week
- for class projects the key is okay to be shared, but for real apps it should be kept secret. Anyone can see the DevTools and find the key. 
- Images is not just pixels, but also an array of numbers that represent the color of each pixel. 
- For a 2x2 image (4 pixel) image we need 16 values.
- The red filter for the tiger image is not just red, but also has some green and blue values.
- The grayscale filter is not just the average of the RGB values, but a weighted average that takes into account human perception. If you make values smalles it gets darker and darker. 
- The negative filter is not just the inverse of the RGB values, but also takes into account the alpha channel (transparency).
- To blur a picture you get all the pixels around a pixel and average them.
