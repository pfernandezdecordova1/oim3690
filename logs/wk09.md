## Review Questions From Class

- You wrote const btn = document.querySelector('button') but clicking the button does nothing. What line of code is missing? You need to add an event listener to the button to tell it what to do when it's clicked. For example: `btn.addEventListener('click', function() { /* code to run on click */ });`

- document.querySelector('myButton') returns null, but <button id="myButton"> is right there in the HTML. What's wrong? Remember that querySelector needs a selector, so it should be document.querySelector('#myButton') to find the element by its id.

- You changed a heading's color in the Console and it worked. After refreshing the page, it's gone. Why? Because the change you made in the Console is temporary and only exists in that session. When you refresh the page, it reloads the original HTML and CSS, so any changes made in the Console will be lost.

- You see onclick="doSomething()" in someone's HTML. What's a better way to set up that event in JavaScript, and why?  A better way is to use addEventListener in your JavaScript file, like this: `element.addEventListener('click', doSomething);`. This keeps your HTML clean and separates your structure (HTML) from your behavior (JavaScript), which is a good practice for maintainability and readability.
