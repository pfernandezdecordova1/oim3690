# Where is the script tag? 
- The script tag holds all the JavaScript code
- Put it at the bottom of the HTML file, before body ends, so it loads after the page content

- `innerHTML` - changes the content inside an element
- `appendChild()` - adds a new element to the page
- `style.display` - shows or hides an element
- `className` - changes the CSS class of an element

- We can use external files to add JavaScript to our HTML. This makes it easier to read. I added a `todo.js` file and linked it to my HTML file. I can write all my JavaScript in that file and it will work on the page. It makes it super clean.
