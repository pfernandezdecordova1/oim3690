- Array: The value that stores multiple values in a sequence.
- Script tag is how you include JavaScript in your HTML. You can put it in the head or body, but it's often best to put it just before the closing body tag for better performance.
- Add Event Listeners: You can use `addEventListener` to make your page interactive. The specific event you listen for (like 'click' or 'mouseover') determines when the function will run. 
- The change in the DOM is the way that JavaScript can manipulate the structure and content of a web page. This allows for dynamic updates without needing to reload the page, making it more interactive and responsive to user actions.

- Build todo html page with JavaScript (vanilla JavaScript) which is a simple way to create a dynamic web page without using any libraries or frameworks.
